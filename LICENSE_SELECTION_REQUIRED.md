# License Selection Required Before Publication

This folder deliberately does not contain a `LICENSE` file and does not grant permission to copy, publish, modify, or redistribute its contents.

The parent research repository has a restrictive Microsoft Research license. That parent license must not be assumed to authorize extracting, relicensing, or publicly distributing these files. Some LDC files may also contain original or adapted work whose provenance needs separate confirmation.

Before making a public GitHub repository:

1. Identify the author and provenance of every source, config, and protocol document in [PUBLIC_RELEASE_MANIFEST.md](PUBLIC_RELEASE_MANIFEST.md).
2. Confirm that an authorized rights holder can license each item for public distribution.
3. Select an appropriate license with institutional/legal guidance.
4. Add the approved `LICENSE` file and matching `pyproject.toml` metadata.
5. Replace the citation template placeholders and record third-party notices, if any.
6. Re-run the publishing checklist.

This notice is a release blocker, not legal advice.
